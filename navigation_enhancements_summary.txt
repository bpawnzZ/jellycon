JellyCon Navigation Enhancement: Comprehensive Navigation Overhaul
==================================================================

## Executive Summary

This comprehensive enhancement significantly improves JellyCon's user experience through three major navigation improvements:

1. **Folder Navigation System** - New file-system style browsing for intuitive library exploration
2. **Favorites Organization** - Enhanced favorites management with unified and categorized views  
3. **Navigation Consolidation** - Reorganized menu structure with added genre browsing capabilities

The changes provide users with multiple intuitive ways to browse their media libraries while maintaining full backward compatibility.

## Key Features Implemented

### 1. Folder Navigation System
- **File-System Style Browsing**: Intuitive folder-based navigation similar to desktop file explorers
- **Library Integration**: Seamless integration with existing Jellyfin library structure
- **Parent Navigation**: Automatic ".. (Parent)" or ".. (Root)" navigation for moving up folder levels
- **Comprehensive Folder View**: "All Folders" option for complete library exploration
- **Performance Optimized**: Efficient API usage with proper caching

### 2. Favorites Organization Enhancement
- **Unified Favorites View**: Single comprehensive view of all favorited content
- **Categorized Favorites**: Organized folder view with media type categories:
  - Movies
  - TV Shows  
  - Music
  - Other Media (BoxSets, MusicVideos, Photos, Books, Games)
- **Improved Discovery**: Better navigation and content discovery for favorite items
- **Backward Compatibility**: No breaking changes to existing favorites functionality

### 3. Navigation Consolidation & Genre Integration
- **Consolidated Library Navigation**: Moved "Browse Folders" and "All Favorites" from main menu root to "Jellyfin Libraries" directory
- **Added "Browse Genres"**: New navigation option providing access to Jellyfin's genre categorization
- **Cleaner Main Menu**: Reduced clutter with only essential high-level options
- **Organized Browsing Experience**: All library exploration methods in one location
- **Enhanced Folder Browsing**: Removed redundant "File System" option for cleaner interface

### 4. Genre Browsing Integration
- **Four Genre Categories**:
  - Movie Genres
  - TV Show Genres
  - Music Genres
  - Mixed Genres (Movies & TV Shows combined)
- **Leverages Existing Infrastructure**: Uses proven `show_genre_list()` function
- **Seamless Integration**: Full compatibility with existing genre API endpoints

```python
def display_favorites_by_type(params):
    """Display favorites organized by media type"""
    base_params = {
        "UserId": user_id,
        "Filters": "IsFavorite",
        "Recursive": True,
        "IsMissing": False,
        "Fields": get_default_filters(),
        "ImageTypeLimit": 1,
        "SortBy": "SortName",
        "SortOrder": "Ascending"
    }
    
    # Movies favorites
    movie_params = base_params.copy()
    movie_params["IncludeItemTypes"] = "Movie"
    # TV Shows favorites
    tv_params = base_params.copy()
    tv_params["IncludeItemTypes"] = "Series"
    # Music favorites
    music_params = base_params.copy()
    music_params["IncludeItemTypes"] = "MusicAlbum,Audio"
    # Other media favorites
    other_params = base_params.copy()
    other_params["IncludeItemTypes"] = "BoxSet,MusicVideo,Photo,Book,Game"
```

```python
def display_genres_view(params):
    """Display genre browsing options"""
    handle = int(sys.argv[1])
    xbmcplugin.setContent(handle, 'files')

    # Movie genres
    add_menu_directory_item(translate_string(30688),
                            "plugin://plugin.video.jellycon/?mode=GENRES&item_type=movie")
    # TV Show genres
    add_menu_directory_item(translate_string(30689),
                            "plugin://plugin.video.jellycon/?mode=GENRES&item_type=tvshow")
    # Music genres
    add_menu_directory_item(translate_string(30690),
                            "plugin://plugin.video.jellycon/?mode=GENRES&item_type=MusicAlbum")
    # Mixed genres
    add_menu_directory_item(translate_string(30691),
                            "plugin://plugin.video.jellycon/?mode=GENRES&item_type=mixed")

    xbmcplugin.endOfDirectory(handle)
```
